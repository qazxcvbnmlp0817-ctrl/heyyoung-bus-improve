# 목포대 통학버스 정류장 검색

내 정류장 이름으로 목포대학교 통학버스 시간을 찾는 모바일 웹사이트입니다.

- 배포 링크: (배포 후 링크를 적어 주세요. 예: `https://<GitHub 사용자명>.github.io/<저장소 이름>/`)

## 프로젝트 목적

헤이영 캠퍼스 앱의 통학버스 화면은 **노선(종착지) 기준**으로 되어 있습니다.
그래서 내가 타는 정류장의 버스를 찾으려면 노선을 하나씩 눌러 확인해야 하고,
많은 학생이 결국 학생지원과의 노선표 PDF를 따로 열어 찾는 방식으로 우회합니다.

이 프로젝트는 시작점을 **정류장**으로 바꿔서, 정류장 이름 하나만 검색하면
그 정류장을 지나는 버스를 시간순으로 바로 볼 수 있게 하는 것을 목표로 합니다.

## 사용자 요구사항과 구현 방법

| 요구사항 | 구현한 기능 |
| --- | --- |
| 1. 정류장 검색 | 화면 맨 위 검색창에 정류장 이름을 입력하면 자동완성 목록이 뜹니다. 띄어쓰기와 끝에 붙은 "건너편", "앞", "승강장" 같은 말을 무시하고, `stopAliases`의 별칭도 함께 써서 이름이 조금 달라도 같은 정류장으로 찾습니다. 정류장을 고르면 그 정류장을 지나는 버스가 시간순 카드로 나옵니다. |
| 2. 예상 소요 시간 | 카드마다 이 정류장 도착 시각과 소요 시간을 보여줍니다. 등교는 "이 정류장 → 학교", 하교는 "학교 → 이 정류장" 기준입니다. 시간표에 적힌 시간은 그대로 쓰고, 비어 있는 정류장은 계산한 예상값을 "약"을 붙여 따로 표시합니다. (아래 [예상 시간 계산 방식](#예상-시간-계산-방식) 참고) |
| 3. PDF 없이 시간표 보기 | PDF 노선표를 JSON 데이터(`bus-data.json`)로 옮겨, 등교/하교 전환 버튼과 카드 화면으로 바로 볼 수 있게 했습니다. 카드의 "운행 경로 보기"를 누르면 노선 전체 정류장과 시간이 나와 PDF를 열 필요가 없습니다. |

## 주요 기능

- 정류장 이름 검색과 자동완성 (키보드 ↑↓·Enter로도 선택 가능)
- 이름이 조금 다른 정류장을 하나로 묶기 (예: "광천파출소" = "광천파출소건너편")
- 자동완성에 정류장별 운행 대수 표시 (0대인 쪽은 숨김)
- 등교/하교 전환 버튼
- 버스 카드: 노선 이름, 이 정류장 시각, 예상 소요 시간, 운행 요일, 2대 운행 여부, 비고
- 운행 경로 보기: 노선 전체 정류장과 시각 (선택한 정류장 강조)
- 버스가 없을 때 반대 방향 버스 바로 보기 버튼
- PDF 쪽수·표기 차이를 말하는 비고는 "운행 요일·경유지는 학생지원과 공지를 확인하세요"로 바꿔 표시
- 스마트폰 화면 기준 디자인, 큰 버튼
- 하단 안내: "노선과 시간은 상황에 따라 바뀔 수 있으니 학생지원과 공지를 확인하세요"와 학생지원과 연락처

## 예상 시간 계산 방식

원본 노선표에는 시간이 비어 있는 정류장이 많습니다. 등교 노선 40개 중 학교 도착 시간이 적힌 노선은 2개뿐이고,
하교 노선은 대부분 도림캠퍼스 출발 시간만 있습니다. 그래서 빈 시간은 아래 방법으로 채웁니다.

1. 앞뒤 정류장에 시간이 있으면 그 사이를 구간별 이동 시간 비율로 나눕니다.
2. 뒤쪽에 시간이 없으면 마지막으로 알려진 시간에 평균 이동 시간을 더합니다.

| 구간 | 이동 시간 | 근거 |
| --- | --- | --- |
| 광주 시내 정류장 사이 | 5분 | 시간표 평균 (120개 구간) |
| 도림캠퍼스 ↔ 에너지밸리캠퍼스 | 35분 | 시간표 값 |
| 목포 시내 정류장 사이 | 3분 | 임의로 정한 값 |
| 해남권 정류장 사이 | 7분 | 임의로 정한 값 |
| 도림캠퍼스 ↔ 광주 정류장 | 50분 | 임의로 정한 값 |
| 도림캠퍼스 ↔ 목포·해남권 정류장 | 25분 | 임의로 정한 값 |
| 에너지밸리캠퍼스 ↔ 광주 정류장 | 25분 | 임의로 정한 값 |
| 도림캠퍼스와 가까운 정류장 (무안우체국, 남악애시앙 등) | 10~25분 | 임의로 정한 값 |

**한계:** 계산한 값은 실제 운행 시간이 아닙니다. 화면에는 항상 "약"과 "예상" 표시를 붙여 실제 시간표 값과 구분합니다.
값은 `app.js`의 `ESTIMATE`에서 바꿀 수 있습니다.

## 사용한 기술

- HTML, CSS, JavaScript (프레임워크, 서버 없음)
- `fetch`로 같은 폴더의 `bus-data.json`을 불러와 사용
- GitHub Pages로 배포

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 모바일 디자인 |
| `app.js` | 검색, 자동완성, 정류장 묶기, 예상 시간 계산, 카드 표시 |

| `PROMPTS.md` | 개발에 사용한 프롬프트 기록 |
